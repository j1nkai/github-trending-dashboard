27,107
2,973
Jupyter Notebook
仓库简介

AirLLM 70B inference with single 4GB GPU

痛点与背景

在本地推理 70B 级别大语言模型时，通常需要 140GB 以上显存，消费级显卡（如 4GB/8GB 显存）完全无法直接载入模型权重，造成极高的硬件部署门槛。

核心突破与功能

AirLLM 实现了在单张 4GB 显存的普通显卡上直接运行 70B 规模超大语言模型推理的能力，且无需对模型权重进行高损量化削减。

关键技术亮点
  • 逐层按需调入内存：将 Transformer 网络层按需切分并流式调入 GPU 显存，大幅降低显存占用达 90%；
  • 内存与显存张量流式传输：优化内存与显存传输通道，重叠计算与传输延迟。
适用场景

适合需要在普通个人电脑、消费级显卡或边缘计算设备上本地运行超大模型推理的开发者与研究人员。

架构启示

打破硬件壁垒的极限显存优化方案，大幅降低超大模型的本地使用成本。
